# Contributing to Chitti

Thank you for your interest in contributing to Chitti.

Chitti is an open-source modern platform for managing chit funds and community finance. We believe financial software should be transparent, secure, reliable, and beautifully designed.

We welcome contributions from developers, designers, product thinkers, security researchers, documentation writers, and community members.

---

## Our Principles

Before contributing, please understand our core principles:

- Security first
- Privacy by design
- Clean and maintainable code
- Excellent user experience
- Transparent development
- Backward compatibility
- Community-driven improvement

---

# Ways to Contribute

You can contribute by:

## Engineering
- Building new features
- Fixing bugs
- Improving performance
- Writing tests
- Improving architecture

## Product & Design
- Improving user experience
- Designing interfaces
- Reviewing workflows
- Creating prototypes

## Documentation
- Improving guides
- Writing tutorials
- Creating examples

## Community
- Reporting issues
- Answering questions
- Sharing feedback

---

# Development Workflow

## 1. Create an Issue

Before starting major work:

- Search existing issues
- Create a new issue if needed
- Explain the problem or proposal clearly

For large features, discuss the approach before implementation.

---
