# Backend Services

This directory contains backend services powering Chitti.

## Planned Services

## API Service

```
services/api
```

Main backend application.

Responsibilities:

- Authentication
- Business logic
- Database operations
- API endpoints


## Notification Service

```
services/notification
```

Handles:

- Email
- SMS
- WhatsApp
- Push notifications


## Worker Service

```
services/worker
```

Handles background jobs:

- Payment reminders
- Report generation
- Scheduled tasks


## Design Approach

Services are designed to be:

- Secure
- Scalable
- Independently maintainable
