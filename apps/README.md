# Applications

This directory contains user-facing applications built for Chitti.

## Applications

### Web Dashboard

Location:

```
apps/web
```

Purpose:

Admin and operator dashboard for managing:

- Members
- Chit groups
- Payments
- Auctions
- Reports
- Analytics


### Mobile Application

Location:

```
apps/mobile
```

Purpose:

Mobile experience for:

- Members
- Field staff
- Operators

Features:

- Payment tracking
- Notifications
- Digital receipts
- Account information

---

## Development Principle

Applications should share common:

- Design system
- Authentication
- API contracts
- Type definitions
